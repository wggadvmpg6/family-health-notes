# 【疫情防治·保健康 防重症】三明市中西医结合医院全力做好新冠肺炎患者医疗救治药品储备工作

> 更新时间：2026-09-17 (UTC+8)

为深入贯彻党中央、国务院决策部署，做好新冠肺炎疫情医疗救治工作，落实“保健康、防重症”要求，三明市中西医结合医院按上级部署做好新冠肺炎患者医疗救治药品储备等工作。

**防治疫情，药学人在行动**

1

**药品储备**** / **做好药品保障

结合三元区南部人口情况，为应对药品库存紧张局面，药学部发挥科室优势，根据我院“中药防疫三件套”处方（**新****冠预防方、新冠治疗方、沉桂辟秽香囊**），调动人力、物力，利用医院场地空余，做好药品原料储备，为疫情防控做好基础保障。

2

**中药有方 / **做好药品供应

自院部发布“中药防疫三件套”起，中药房每日均调剂储备千余人份预防方、治疗方。煎药房灵活排班，五班制倒班，机器不停歇，加班加点煎煮中药以抗疫；临方炮制室每日调剂配制预防香囊500余袋。截至目前煎煮万余袋防疫中药、供应香囊8000余袋。

3

**全力抗疫 / **党员带头战疫

为保障我院所有药学窗口正常运转，党员、团员发挥先锋模范作用，成立支援突击队，药学部办公室、临床药学室全员带头参加支援，其余部门以自愿报名形式，接龙总计20余人。

同时，为了保障预防香囊储备，在院党委全力支持下，在全院招募党员志愿者协助药学部完成预防香囊制作。

随着发热门诊病人日渐增加，门诊西药房窗口工作量剧增，党员发挥带头作用，药房全体人员，主动加班加点，做好窗口发药工作。
