# 贴一贴，长一长 | 春季“助长贴”，让孩子的身高「上春山」

> 更新时间：2026-09-16 (UTC+8)

**长高的秘密**

《黄帝内经》记载：“春三月，此谓发陈。天地俱生，万物以荣。”

春季，自然界阳气升发，万物始生，是儿童生长的“黄金季”。世界卫生组织调查数据显示：春季（3月至5月）儿童身高增长速度是秋冬季节的2～2.5倍。

**“助长贴”**是结合春季升发特性，将特制的中药膏贴敷于人体相应穴位，通过药物对穴位持续地刺激，增强孩子脾胃功能，改善睡眠质量，提高抵抗力，从而达到助长高、增免疫的目的。

**哪些孩子适合助长贴？**

1. 身高增长缓慢或低于同龄儿童平均身高。

2. 体重偏轻，脾胃虚弱易消化不良食积。

3. 夜间睡眠障碍、容易惊醒，入睡困难。

4. 体质差、反复感冒者。

**注：**骨骺线完全闭合者，已无长高空间，不适合做此治疗。

**贴敷时间：**

1. 即日起至2024年5月5日，每周六周日下午休息，具体以预约挂号为准。

2. 每周贴敷一次，4～6周一疗程。建议连续贴敷3年。

**不宜贴敷儿童：**

1. 年龄2岁以下小儿不宜贴敷；

2. 严重过敏体质及皮肤破损者不建议贴敷；

3. 感冒发热、急性胃肠炎、尿路感染等急性炎症疾病、慢性疾病急性发作期儿童均不宜贴敷。

**贴敷注意事项：**

1. 敷贴时长：≥10岁儿童4～6小时，3～9岁儿童2～4小时，贴敷部位出现皮疹、瘙痒时请及时去除。

2. 敷贴后4小时内不宜洗澡，敷贴当天禁止游泳。

3. 贴敷后局部可能出现细小水泡、淡褐色色素沉着，为正常现象。贴敷处皮肤破裂而引起感染者，应及时就医。

4. 贴敷期间避免食用辛辣、生冷、海鲜、油炸等刺激性食物，并保证充足睡眠时间，多做纵向运动，如跳绳、摸高等运动。
